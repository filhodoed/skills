# filhodoed/skills

Public [Agent Skills](https://docs.claude.com/en/docs/claude-code/skills) for Claude Code, installable as a plugin.

## Skills

| Skill | What it does |
| --- | --- |
| [mof](skills/mof/README.md) — Map of Functions | Models a system's functions, dependencies, and blast radius so agents plan changes with full context instead of guessing — and can turn the map into an interactive HTML diagram on request. |

## Installation

Install the whole plugin (every skill in this repo):

```
/plugin marketplace add filhodoed/skills
/plugin install filhodoed-skills@filhodoed
```

Or try a single skill without installing it — see that skill's own README for the copy command.
